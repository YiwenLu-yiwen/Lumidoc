# Lumidoc 核心模块

本目录包含Lumidoc项目的核心模块代码，每个模块都是一个独立的微服务，可以单独部署和扩展。

## 模块结构

### 1. 文件处理模块 (`modules/file`)

负责文件的上传、处理、解析和管理。支持多种文档格式，包括PDF、Word、Excel、图片等。

主要功能：
- 文件上传和存储
- 文档解析和提取
- OCR图像识别
- 文件元数据管理

### 2. RAG模块 (`modules/rag`)

检索增强生成服务，将文档内容向量化并进行语义检索。

主要功能：
- 文档分块和向量化
- 向量索引和检索
- 上下文组装和排序
- 语义相似度计算

### 3. 图谱模块 (`modules/graph`)

知识图谱服务，负责构建和查询实体关系网络。

主要功能：
- 实体和关系提取
- 图谱构建和存储
- 图谱查询和可视化
- 图谱推理

### 4. 对话模块 (`modules/chat`)

多模态对话服务，支持基于文档的智能对话。

主要功能：
- 对话管理
- 上下文维护
- 多轮对话理解
- 文档引用和追溯

### 5. 问答模块 (`modules/question`)

问答服务，专注于从文档中提取答案。

主要功能：
- 问题分析和分类
- 精确答案提取
- 多文档综合分析
- 答案可信度评估

### 6. 认证模块 (`modules/auth`)

用户认证和授权服务。

主要功能：
- 用户注册和登录
- 权限管理
- 访问控制
- API密钥管理

### 7. 监控模块 (`modules/monitoring`)

系统监控和日志服务。

主要功能：
- 服务健康检查
- 性能监控
- 用量统计
- 日志收集和分析

## 模块间通信

各模块之间通过RESTful API进行通信，遵循以下原则：

1. 模块接口清晰定义，使用共享的类型定义
2. 错误处理统一，使用标准的错误码和消息格式
3. 异步任务通过Redis队列传递
4. 状态和进度可查询

## 开发指南

1. 每个模块都有独立的README文件和配置说明
2. 开发新功能时应遵循现有的架构和设计模式
3. 所有API都应有完整的文档和类型定义
4. 模块可独立测试和部署

## 目录结构

```
src/
├── modules/               # 功能模块（可独立部署为微服务）
│   ├── auth/              # 用户认证模块
│   ├── file/              # 文件处理模块
│   ├── rag/               # 检索增强生成模块
│   ├── graph/             # 知识图谱模块
│   ├── project/           # 项目管理模块
│   ├── question/          # 问题生成与处理模块
│   ├── chat/              # 聊天对话模块
│   ├── llm/               # 大语言模型集成
│   ├── monitoring/        # 监控与健康检查
│   └── lightraglocal/     # 轻量级RAG引擎
├── services/              # 共享服务层
│   ├── llm_service.py     # LLM服务接口
│   └── rag_service.py     # RAG服务接口
├── core/                  # 核心配置和工具
│   ├── config.py          # 配置管理
│   ├── logging.py         # 日志系统
│   └── exceptions.py      # 异常定义
├── shared/                # 共享类型和工具
│   ├── types/             # 共享数据类型
│   └── utils/             # 共享工具函数
├── database/              # 数据库相关
├── models/                # 数据模型定义
└── main.py                # 示例入口点
```
