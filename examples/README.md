# LightRAG 功能测试

本目录包含了对LightRAG功能进行测试的示例代码。

## 测试脚本说明

### test_lightrag.py

该脚本用于测试LightRAG的基本功能，包括：

1. **生成知识图谱** - 测试LightRAG是否能够从文档内容生成知识图谱
2. **文档管理功能**
   - 单文件插入测试
   - 多文件插入测试
   - 文档删除测试
   - 批量文件处理测试
   - 从图谱删除文件测试
3. **检索功能**
   - 基础文档查询功能
   - 语义搜索功能
   - 文档列表查询功能

## 如何运行测试

### 前提条件

确保LightRAG服务已经启动。默认测试脚本会连接到`http://localhost:8012`进行测试。

### 安装依赖

```bash
pip install httpx asyncio
```

### 运行测试

```bash
# 切换到项目根目录
cd /path/to/STP

# 运行测试脚本
python examples/test_lightrag.py
```

### 指定自定义服务地址

如果LightRAG服务运行在不同地址，可以通过环境变量指定：

```bash
# 指定自定义服务地址
LIGHTRAG_SERVICE_URL=http://your-lightrag-service-url python examples/test_lightrag.py
```

## 测试数据说明

测试脚本使用了预设的测试文档，主题为"溯溪鞋"相关内容，包括：
1. 产品介绍
2. 制造工艺
3. 市场分析

这些测试文档用于评估LightRAG对Markdown格式内容的处理能力，以及对结构化文本的知识抽取能力。

## 测试结果解读

测试脚本会输出详细的测试过程和结果。成功的测试应该显示所有功能都能正常工作，包括：

- 单文档和多文档插入成功
- 查询能够返回相关答案
- 搜索能够返回相关结果
- 文档删除操作成功
- 批量处理操作成功
- 删除文件从图谱操作成功

如果某个功能测试失败，会通过断言错误指出具体的失败点。
