# Lumidoc Frontend

这是 Lumidoc 项目的前端目录，已经从 Open WebUI 框架中彻底清理。

## 技术栈
- React + TypeScript + Vite
- TailwindCSS
- 企业级组件库

## 开发命令

```bash
cd frontend
npm install
npm run dev
```

## 架构
- 微服务后端 API 集成
- 响应式设计
- 现代化 UI/UX
